# Lift Service Management System (LSMS)

A system for managing lift maintenance and service operations.

## Phase 1 Modules
- Login and user roles
- Customer and lift register
- Service job management
- Maintenance checklist
- Service reports
- Office dashboard

## Applications
- Technician mobile application
- Office management dashboard

## Planned Technology
- Frontend: mobile-friendly web application
- Backend: Python FastAPI REST API
- Database: PostgreSQL

## Development Status
Project setup in progress.
